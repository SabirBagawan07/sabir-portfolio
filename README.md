# Sabir Mubin Bagawan — Personal Portfolio

Modern, responsive personal portfolio website built with React, Vite, Tailwind CSS, Lucide React, and Framer Motion.

## Target Position
- Data Analyst
- Python Developer
- Entry-level Data / AI Roles

## Technologies Used
- React (Vite template)
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
